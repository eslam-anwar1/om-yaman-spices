## 🚀 التشغيل والنشر (Deployment Guide)

### أولاً: التشغيل المحلي السريع (Local Development)

#### 1. باستخدام خادم PHP المدمج (الأسهل):
```bash
cd om-yaman-spices
php -S localhost:8000
```
افتح المتصفح على: `http://localhost:8000`  
وللوحة الإدارة: `http://localhost:8000/admin.php`

#### 2. فتح الملفات مباشرة أو عبر Live Server:
يمكنك فتح `index.html` و `admin.html` في أي متصفح، وسيعمل المتجر والسلة والواتساب بشكل كامل بفضل نظام التوافق الاحتياطي (Zero Blank Screens Guarantee).

---

### ثانياً: النشر عبر Docker

1. **بناء الحاوية (Build Image)**:
```bash
docker build -t om-yaman-spices .
```

2. **تشغيل الحاوية (Run Container)**:
```bash
docker run -d -p 8080:80 --name om-yaman-app om-yaman-spices
```
تصفح التطبيق عبر: `http://localhost:8080`

---

### ثالثاً: النشر السحابي على Render (Cloud Deployment)

الملف `render.yaml` و `Dockerfile` مهيآن بالكامل للنشر الفوري على منصة Render:

1. ارفع المشروع إلى مستودع GitHub أو GitLab.
2. ادخل إلى لوحة تحكم **Render** واختر **New Web Service**.
3. اربط مستودع المشروع، وسيكتشف Render تلقائياً الـ `Dockerfile` أو استخدم خيار **Blueprint** باختيار `render.yaml`.
4. خصائص النشر المضمنة:
   - **Environment**: Docker
   - **Port Handling**: يدعم سكريبت `docker-entrypoint.sh` المنفذ الديناميكي المتغير الذي يُمرره Render تلقائياً في المتغير البيئي `PORT`.
   - **Health Check**: تم ضبطه على `/api.php?action=get_categories`.
5. اضغط **Deploy Web Service**، وخلال دقيقتين سيكون المتجر متاحاً عالمياً برابط مباشر وشهادة SSL مجانية بدون أي أخطاء 404 أو توقف بالخادم!
